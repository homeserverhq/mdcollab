# Integrations

| environment variable | default | example                             | description                                                                                                                          |
|----------------------|---------|-------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| `MDCOLLAB_PLANTUML_SERVER` | -       | `https://www.plantuml.com/plantuml` | The PlantUML server that mdCollab uses to render PlantUML diagrams. If this is not configured, PlantUML diagrams won't be rendered.  |
