# Security Policy

## Supported Versions

Only the latest release of mdCollab is supported. We don't have the
resources to maintain multiple versions.

## Reporting a Vulnerability

Please use the private security advisory feature of the
[mdCollab repository](https://github.com/homeserverhq/mdcollab/security/advisories/new).
This allows you to get in direct, but private contact with the maintainers.

Please provide as much information as possible so that the maintainers can
make an informed decision about the submitted report.

When your findings are accepted as a security issue, we'll work on a fix or
at least a workaround for the next release. With the release that contained
the fix, we want to encourage you to publish your findings as you like.

We'll also credit you in the release notes.

When your findings are not accepted as a security issue, feel free to write
a fix yourself and contribute it to mdCollab, as well as publish them as you
like and allow people to make an informed decision about using mdCollab.
